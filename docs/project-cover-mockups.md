# Project cover mockups

Created with the built-in image generation tool. These are illustrative product presentations, not screenshots or performance evidence. Existing case-study screenshots and repository evidence remain separate.

Direction: large app windows, a focused overlapping UI detail, strong typography, and a project-specific tonal backdrop. The initial sculptural concepts were rejected and are not used.
